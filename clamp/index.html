RESPONSIVE · FLUID TYPE

clamp · rem · vw
같이 쓰는 법

브라우저 창 너비를 줄였다 늘렸다 해 보세요. 이 제목도 clamp()로 만들어서, 375px에서 32px, 1920px에서 72px 사이를 자연스럽게 오가요.

1. clamp는 세 칸 2. 고정 + 늘어나는 부분 3. vw만 쓰면 안 되는 이유 4. clamp와 vw의 관계 5. 숫자 구하는 법 6. 실습

STEP 1

clamp는 세 칸이에요

/* clamp(최소값, 선호값, 최대값) */
font-size: clamp(2rem,  1.393rem + 2.59vw,  4.5rem);

브라우저는 가운데 선호값을 먼저 계산해요. 그 값이 최소값보다 작으면 최소값을, 최대값보다 크면 최대값을 써요.

알아두기

clamp(A, B, C)는 max(A, min(B, C))와 같아요. B가 C를 넘지 않게 자르고, A보다 작아지지 않게 올리는 거예요. "clamp는 max와 min을 한 번에 쓰는 지름길"이에요.

STEP 2

가운데 값은 "고정 부분 + 늘어나는 부분"이에요

1.393rem은 고정 부분이에요. 약 22px로, 화면 너비와 상관없이 항상 깔려 있어요.
2.59vw는 늘어나는 부분이에요. 화면 너비의 2.59%라서 화면이 넓어질수록 커져요.

비유하면 기본급(rem) + 성과급(vw)이에요. 기본급은 누구나 받고, 성과급은 화면이 넓을수록 많이 받아요. 그리고 clamp가 "최저 32px, 최고 72px"로 상한과 하한을 정해요.

STEP 3

왜 vw만 쓰면 안 될까요?

font-size: 8.53vw처럼 vw만 써도 375px에서 32px가 나와요. 하지만 vw는 화면 너비만 보는 단위라서, 사용자가 브라우저 설정에서 글자 크기를 키워도 반영되지 않아요. 눈이 불편해서 글자를 크게 설정해 둔 사람에게도 글씨가 그대로 보이는 거죠.

rem은 브라우저 기본 글자 크기를 기준으로 해요. rem을 섞어 두면 사용자가 글자 크기를 키울 때 고정 부분, 최소값, 최대값이 모두 같이 커져요.

브라우저 기본 글자 크기 바꿔 보기 (설정 변경을 흉내 내요)

8.53vwvw만 → -
MOOD
clamp(2rem, 1.393rem + 2.59vw, 4.5rem)rem + vw → -
MOOD

버튼을 눌러 보면 rem + vw 쪽만 커지고, vw만 쓴 쪽은 그대로예요. (넓은 화면에서 vw만 쓴 글씨가 상자를 넘치는 것도 같은 문제예요.)

STEP 4

clamp와 vw의 관계

한 문장으로 말하면 vw는 "늘어나게 하는 힘", clamp는 "멈추게 하는 울타리"예요. 둘은 역할이 달라서 같이 써야 완성돼요.

이렇게 쓰면결과
font-size: 8.53vw
vw만		멈추지 않아요. 320px 휴대폰에서 27px, 1920px 모니터에서 164px, 2560px에서 218px까지 커져요.
clamp(32px, 40px, 72px)
clamp만		아무 일도 안 일어나요. 가운데가 고정값이라 항상 40px예요.
clamp(2rem, 1.393rem + 2.59vw, 4.5rem)
둘을 합치면		"자라다가 멈추는" 크기가 돼요. 32px 아래로도, 72px 위로도 가지 않아요.

화면 폭에 따른 글자 크기 (세로 점선 = 지금 내 화면)

vw만 (8.53vw) clamp 없이 (1.393rem + 2.59vw) clamp 적용
하는 일혼자 쓰면
vw화면 폭에 따라 값을 바꿈끝없이 커지거나 작아짐
rem사용자 글자 설정을 반영함화면 폭에 반응하지 않음
clamp최소값과 최대값을 정함가운데가 고정값이면 의미 없음

clamp는 폰트 전용이 아니에요

좌우 여백, 섹션 간격처럼 길이를 쓰는 곳이면 어디든 쓸 수 있어요. 이 페이지의 좌우 여백과 섹션 간격도 clamp로 만들었어요.

--gutter: clamp(16px, 10.74vw - 24.29px, 182px);  /* 좌우 여백 16 → 182 */

STEP 5

숫자 구하는 법

"375px에서 32px, 1920px에서 72px"처럼 원하는 값만 정하면 돼요.

/* ① 늘어나는 부분(vw) = (최대 크기 - 최소 크기) ÷ (최대 화면 - 최소 화면) × 100 */
(72 - 32) ÷ (1920 - 375) × 100 = 2.59vw

/* ② 고정 부분(px) = 최소 크기 - vw값 × (최소 화면 ÷ 100) */
32 - 2.59 × 3.75 = 22.29px

/* ③ 고정 부분을 rem으로 = px ÷ 16 */
22.29 ÷ 16 = 1.393rem

/* ④ 조립 */
font-size: clamp(2rem, 1.393rem + 2.59vw, 4.5rem);

STEP 6

실습

화면 375px ~ 1920px 기준으로 직접 계산해 보세요. 다 풀고 계산기로 확인해도 좋아요.

Q1. 섹션 타이틀: 20px → 30px (rem 사용)

vw = (30 − 20) ÷ 1545 × 100 = 0.647vw
고정 = 20 − 0.647 × 3.75 = 17.57px → 1.098rem

font-size: clamp(1.25rem, 1.098rem + 0.647vw, 1.875rem);
Q2. 섹션 사이 간격: 24px → 40px (px 사용)

vw = (40 − 24) ÷ 1545 × 100 = 1.04vw
고정 = 24 − 1.04 × 3.75 = 20.12px

gap: clamp(24px, 1.04vw + 20.12px, 40px);

레이아웃 여백은 글자 설정과 관계가 적어서 px로 써도 괜찮아요.

Q3. 아이콘 크기: 24px → 45px (rem 사용)

vw = (45 − 24) ÷ 1545 × 100 = 1.359vw
고정 = 24 − 1.359 × 3.75 = 18.9px → 1.181rem

width: clamp(1.5rem, 1.181rem + 1.359vw, 2.8125rem);
Q4. 생각해 보기: clamp(32px, 40px, 72px)는 1920px 화면에서 몇 px일까요?

40px예요. 가운데 값에 vw가 없어서 화면 폭이 바뀌어도 값이 변하지 않아요. clamp는 가운데 값이 변하는 값일 때만 의미가 있어요.

Q5. 생각해 보기: font-size: 5vw의 문제점 두 가지는?

① 최소·최대가 없어서 작은 휴대폰에서는 너무 작고, 큰 모니터에서는 끝없이 커져요.
② 사용자가 브라우저 글자 크기를 키워도 반영되지 않아요. (접근성 문제)
