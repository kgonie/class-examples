폰트 스타일 가이드

메인페이지(Design Prep)에 쓰인 글자 스타일 4가지를 모았어요. 모든 글자 크기는 rem + vw를 섞은 clamp()로 만들어서, 화면 폭 375px → 1920px 사이에서 비율대로 커지고 브라우저 글자 크기 설정도 따라가요. 창 크기를 바꿔 보면 "지금" 값이 바로 바뀌어요.

한눈에 보기

스타일 쓰이는 곳 375px 1920px 지금 굵기 줄 높이 대소문자
Display 히어로 타이틀 (h1) 32px 72px - 700 Bold 1.5 → 1.4 (768px~) 대문자
Title 섹션 타이틀 (h2) 20px 30px - 600 SemiBold 1.5 대문자
Input 검색 입력창 · placeholder 16px 24px - 500 Medium 1.5 그대로
Button 검색 버튼 16px 24px - 500 Medium 1.5 그대로
